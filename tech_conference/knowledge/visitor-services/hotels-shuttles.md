# Hotels and Shuttles

## Recommended Hotels

### Conference Hotel (Official)
**Hotel Congress Palace**
- **Distance:** Connected to venue via indoor walkway
- **Rate:** €120/night (conference rate, book with code TECHCONF2026)
- **Amenities:** Wi-Fi, breakfast, gym, restaurant
- **Booking:** hotels.techconf2026.com
