# Symptom Checker

## When to Go to the Emergency Department

### Chest Pain
- **If accompanied by:** sweating, shortness of breath, pain radiating to arm or jaw
- **Triage:** Code ORANGE
- **Action:** Call 118 immediately, do NOT drive yourself

### Breathing Difficulty
- **Severe:** Cannot speak in full sentences, lips turning blue
- **Triage:** Code RED
- **Action:** Call 118 immediately

- **Moderate:** Short of breath with exertion, can still speak
- **Triage:** Code YELLOW
- **Action:** Go to ED, have someone accompany you

### Bleeding
- **Massive/uncontrolled:** Soaking through bandages, spurting
- **Triage:** Code RED
- **Action:** Apply pressure, call 118

- **Moderate:** Steady flow, controllable with pressure
- **Triage:** Code YELLOW
- **Action:** Go to ED, apply pressure en route

### Fever
- **Above 40°C (104°F) with confusion:**
- **Triage:** Code ORANGE
- **Action:** Go to ED immediately

- **Above 38.5°C (101.3°F):**
- **Triage:** Code GREEN
- **Action:** Consider guardia medica or your GP

### Trauma
- **Severe (car accident, fall from height, head injury):**
- **Triage:** Code RED
- **Action:** Call 118, do NOT move the injured person

- **Minor (sprains, small cuts, bruises):**
- **Triage:** Code GREEN
- **Action:** Consider guardia medica or pharmacy
