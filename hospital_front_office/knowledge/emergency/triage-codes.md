# Emergency Department Triage Codes

## Code RED — Immediate
**Wait time:** 0 minutes — Immediate care
**Conditions:**
- Cardiac arrest
- Severe breathing difficulty
- Massive bleeding
- Unconsciousness
- Severe trauma (car accidents, falls from height)
**Action:** Go directly to ED, call 118 if unable to move

## Code ORANGE — Urgent
**Wait time:** < 15 minutes
**Conditions:**
- Chest pain
- Stroke symptoms (FAST: Face, Arms, Speech, Time)
- Severe abdominal pain
- High fever with confusion
- Compound fractures
**Action:** Proceed to ED immediately

## Code YELLOW — Moderate
**Wait time:** < 60 minutes
**Conditions:**
- Moderate fever
- Minor fractures
- Cuts requiring stitches
- Vomiting/diarrhea with dehydration
- Allergic reactions (mild)
**Action:** Go to ED, expect waiting

## Code GREEN — Minor
**Wait time:** < 120 minutes
**Conditions:**
- Common cold symptoms
- Minor sprains
- Small cuts
- Mild headaches
- Prescription renewals
**Action:** Consider guardia medica or pharmacy first

## Code WHITE — Non-Urgent
**Wait time:** > 120 minutes or redirected
**Conditions:**
- Chronic condition follow-up
- Certificate requests
- Non-urgent specialist visits
**Action:** Redirected to appropriate department or guardia medica
